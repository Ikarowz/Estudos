# Estudos
Descrição do Repositório:

Este repositório contém conteúdos relacionados à Modelagem de Software e exercícios práticos em Java e Python. Ele está dividido em duas seções principais:

Modelagem de Software:

Aqui você encontrará materiais sobre UML, MER e DER, fundamentais para a criação de diagramas e modelagem de sistemas.

Exercícios de Programação:

A pasta TRABALHOS contém uma série de exercícios simples, principalmente em Java, com foco em funções e programas pequenos. Também há alguns exercícios em Python.

Tecnologias Utilizadas:
Java: Para exercícios de programação e desenvolvimento de funções simples.

Python: Para resolução de exercícios em Python.

UML: Para diagramas de modelagem de software.

MER/DER: Para modelagem de banco de dados.
